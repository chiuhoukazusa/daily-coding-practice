# Topological Sort (Kahn + DFS)

日期：2026-08-26
方向：图算法

## 技术点
1. **Kahn 算法（BFS/入度法）** —— 不断取出入度为 0 的顶点，队列贪心生成拓扑序。
2. **DFS 后序（Post-Order + 反转）** —— 深度优先遍历，按完成时间逆序得到拓扑序，并用三色标记（`white/gray/black`）检测反向边。
3. **环检测** —— Kahn 若输出顶点数 < n，或 DFS 遇到 gray 顶点的反向边，则判定图中存在环。
4. **拓扑序合法性验证器** —— 检查所有有向边 `u->v` 均满足 `pos[u] < pos[v]`。
5. **PNG 可视化** —— 10 顶点 DAG 按拓扑秩从左到右分层布局，红→蓝渐变色标顺序，有向边带箭头。
