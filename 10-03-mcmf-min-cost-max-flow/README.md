# Min-Cost Max-Flow（最小费用最大流）— 连续最短路 + 势能 Dijkstra

在带容量、带单位费用的网络上，求**在流量最大前提下总费用最小**的流。核心实现用
**Successive Shortest Paths（连续最短路）** 算法，并配合 **Johnson 式势能（potential）**
把每轮最短路从 Bellman-Ford 的 O(V·E) 优化为 Dijkstra 的 O(E log V)，同时保留对负费用边的支持。

## 问题描述

给定有向网络 G=(V,E)，源点 s、汇点 t。每条边 (u,v) 有容量 `cap(u,v)` 和单位费用 `cost(u,v)`。
目标是：

```
maximize  flow(s→t)
subject to: 0 ≤ f(u,v) ≤ cap(u,v)          (容量约束)
            Σ_v f(u,v) = Σ_v f(v,u)        (中间节点流量守恒)
且在所有最大流中，minimize  Σ f(u,v)·cost(u,v)
```

费用可正可负，但**初始网络不能含负费用环**（否则最小费用无定义/无下界）。

## 算法核心

1. **势能初始化（Johnson 式）**：从“连向所有节点、权 0 的超源”跑 Bellman-Ford，得到势能
   `h[v]`，满足 `h[v] ≤ h[u] + cost(u,v)` 对所有残差边成立 → 重赋权 `w' = cost + h[u] - h[v] ≥ 0`。
2. **Dijkstra 最短增广路**：在非负重赋权图上用 Dijkstra 找 s→t 最短路。
3. **势能更新**：`h[v] += dist[v]`（保持非负重赋权性质）。
4. **沿最短路增广**：增广路径上的最小剩余容量，更新残差网络与总费用。
5. 重复 2–4 直到 s 无法到达 t。此时流量最大、费用最小。

```
势能 Dijkstra: 38.69 ms   Bellman-Ford: 23.48 ms   (加速比 0.6x，结果一致)
```

> **诚实结论**：在本批测试实例上，由于增广轮数（=流量值）有限且 Bellman-Ford 借助
> 提前终止在稀疏残差上接近线性，势能 Dijkstra 的吞吐优势并未体现；两实现结果完全一致。
> 势能 Dijkstra 的渐进优势（O(E log V) vs O(V·E)）在**大规模、稠密、增广轮数多**的网络
> 上才显著。本题的价值在于**正确实现带负权边的势能重赋权机制**，而非在该实例上压过 BF。

## 技术要点

- 势能重赋权（Reduced Cost）保证 Dijkstra 处理的边权非负
- 反向残差边（cost 取负）支撑增广与流量撤销
- Johnson 式超源初始化正确处理负费用边
- 三种独立验证（交叉实现、流量守恒、最大流一致性）确保正确性
