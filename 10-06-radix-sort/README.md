## 技术要点
- **LSD（Least Significant Digit）基数排序**：从最低位（最低字节）到最高位逐轮做稳定排序，利用稳定性的累积效应得到全局有序
- **计数排序作为单轮稳定排序**：基数 256（按字节分桶），通过前缀和 → 逆序摆放到稳定位置
- **负整数处理**：将 `int` 符号位翻转（`^ 0x80000000`）得到单调递增的 `uint32` 映射，使负数能统一用无符号基数排序处理
- **稳定性验证**：将 `(key, id)` 打包成 64 位，验证相等 key 的 id 保持递增
- **性能量化**：与 `std::sort` 对比，加速比约 7.3x（整数数据，线性时间 O(n·d) vs 比较排序 O(n log n)）
