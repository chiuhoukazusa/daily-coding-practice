# Skip List (Probabilistic Ordered Map)

**日期**: 2026-09-22
**方向**: 数据结构
**核心技术**: 跳表 / 随机层级 / 多层链表索引 / 期望 O(log n)

## 概述

跳表（Skip List）是一种概率性的有序映射（ordered map）数据结构，通过多层
排序链表实现对平衡树的概率性模拟。每个节点拥有一个从几何分布（p=0.5）抽取的
随机"高度"，高层链表作为低层链表的"快速索引"。插入/查找/删除的期望复杂度为
O(log n)，且代码远简单于红黑树等平衡 BST。

## 实现要点

- 哨兵 `head` 节点拥有 `MAX_LEVEL=32` 层，指向每层起始。
- `randomLevel()`：几何分布随机层级（每次最高位翻硬币，p=1/2），期望每节点 ~2 层。
- `update[]`：自顶向下下降，记录每层的前驱节点，用于 splice 插入/删除。
- 删除后收缩 `maxLevel`，保持不产生空高层。
