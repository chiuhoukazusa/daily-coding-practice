## 技术要点
- **Z 函数**：对字符串 `S`，`Z[i]` 定义为 `S[0..]` 与 `S[i..]` 的最长公共前缀长度（约定 `Z[0] = 0`）。利用当前最靠右的 Z-box `[l, r)` 复用已匹配信息，`i < r` 时直接取 `min(r - i, Z[i - l])`，再向外暴力扩展，均摊复杂度 O(n)
- **线性时间模式匹配**：构造 `P + '#' + T`（`#` 为不在字符集中的分隔符），对合并串求 Z 函数，T 中每个位置的 `Z[offset + i] >= len(P)` 即表示 P 在此匹配成功，整体 O(n + m)
- **朴素 O(n·m) 基准实现**：逐位置逐字符比较的暴力匹配，用于正确性交叉验证与加速比量化
- **关键陷阱**：全 'a' 文本 + 全 'a' 模式是最坏情况（朴素算法反复匹配不回退，O(n·m)），本实现专门用该配置压测加速比，验证 Z 算法在坏输入下仍保持线性

## 量化验证（非视觉检查）
1. **Z 函数正确性**：7 组边界用例（空串、单字符、全重复、回文等）+ 200 组随机串（小字母表 1~4 易触发大量匹配），线性实现与朴素 O(n²) 结果**逐元素完全一致**
2. **模式匹配正确性**：300 组随机 `(text, pattern)`（小字母表 1~3 制造大量重叠匹配），Z 匹配与朴素 O(nm) 返回位置列表**完全一致**
3. **性能量化（最坏情况加速比）**：全 'a' 制造 O(n·m) 朴素最坏输入，加速比随规模上升 **36x → 102x → 273.9x**，匹配数一致，直观验证从二次到线性的复杂度跨度
