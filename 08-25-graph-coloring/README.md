# Graph Coloring (Welsh-Powell + Backtracking)

日期：2026-08-25
方向：图算法

## 技术点
1. **Welsh-Powell 贪心着色** —— 按度数降序排序后贪心分配最小可用颜色。
2. **回溯精确染色（色数）** —— 对 1..n 种颜色逐一尝试回溯，求得真正的色数 χ(G)。
3. **合法着色验证器** —— 检查所有相邻顶点颜色不同。
4. **二分图 2-可着色检测** —— BFS 二染色，判断图是否二分。
5. **PPM 可视化** —— 圆形布局，顶点按颜色填充、边灰色。

## 量化验证（30/30 通过）
| 验证项 | 结果 |
|--------|------|
| 所有着色合法（无相邻同色） | 8/8 PASS |
| Welsh-Powell 颜色数 ≥ 色数（上界有效） | 8/8 PASS |

| 色数 ≥ 团下界（K5 clique=5） | 1/1 PASS |
