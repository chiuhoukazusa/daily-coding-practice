# Bloom Filter Probabilistic Set

Bloom Filter（布隆过滤器）是一种**概率型集合**数据结构：以极低的内存代价回答「元素是否在集合中」，代价是允许**假阳性（false positive）**——即不在集合中的元素可能被误判为存在，但**绝不会出现假阴性（false negative）**。

## 编译运行

```bash
g++ main.cpp -o bloom -std=c++17 -O2 -Wall -Wextra
./bloom > bloom_filter_output.txt
```

## 技术要点

- **位数组 + 多重哈希**：用 `m` 位的位数组表示集合，插入时对元素做 `k` 个独立哈希，把对应的 `k` 个位置 1；查询时若 `k` 个位全为 1 则判定存在。
- **double hashing 派生 k 个哈希**：`h_i(x) = (h1(x) + i·h2(x)) mod m`，`h2` 强制为奇数以保证与 `m` 相对较好的散布，避免为每个 `i` 单独设计哈希函数。
- **理论 FPR 公式**：`(1 - e^(-kn/m))^k`，其中 `n` 为插入元素数、`m` 为位数、`k` 为哈希函数个数。
- **零假阴性保证**：已插入元素的 `k` 个位必然都是 1，查询一定命中。
- **内存压缩比**：位数组仅 `m/8` 字节，相比 `std::unordered_set` 的桶 + 节点开销压缩数十倍。

## 验证结果（量化）

| k | 理论 FPR | 实测 FPR | 零假阴性 |
|---|---------|---------|---------|
| 3 | 1.5404% | 1.5585% | ✅ 0 |
| 5 | 0.7846% | 0.7770% | ✅ 0 |
| 7 | 0.6501% | 0.6875% | ✅ 0 |
| 10 | 0.7700% | 0.8020% | ✅ 0 |

- **内存压缩比**：30.5x（256 KB vs 约 7.6 MB）。
- **零假阴性**：所有 `n=200000` 个插入元素查询全部命中，无假阴性。
