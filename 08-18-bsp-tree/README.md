# BSP Tree 3D Painter's Algorithm

## 概述

实现二叉空间分割（Binary Space Partitioning, BSP）树，对 3D 场景中的多边形进行视点相关的 **back-to-front 排序**，用于画家算法（Painter's Algorithm）渲染。

画家算法核心思想：按"从远到近"的顺序绘制多边形，后绘制的（较近的）自然遮挡先绘制的（较远的），从而在不使用深度缓冲的情况下得到正确的遮挡关系。BSP 树通过递归地把空间用分割平面切成两半，将"排序"问题转化为一次树遍历，使任意视点下的正确绘制顺序可以在 O(n) 时间内得到。

- 场景多边形数：8（构建 BSP 后细分得到 17 个片段）
- 测试视点数：4
- BSP 画家算法与 z-buffer ground truth **逐像素完全一致**（差异 = 0）的视点数：**4 / 4（100%）**
- BSP 遍历深度顺序验证：OK

## 技术要点

- **BSP 树的构建**：每次选取场景中的一个多边形所在平面作为分割平面，将剩余多边形按平面法线方向分类到 front/back 子空间；跨越平面的多边形被分割为两个片段（这正是 8 → 17 的来源）。
- **视点相关遍历**：给定视点，先递归绘制与视点异侧（远侧）的子树，再绘制当前分割平面上的多边形，最后绘制同侧（近侧）子树，即可得到正确的 back-to-front 顺序。
- **画家算法渲染**：按 BSP 顺序逐个多边形光栅化（关闭 z-buffer），后画的覆盖先画的。
- **ground truth 对照**：用独立实现的 z-buffer 光栅化渲染同一场景作为真值，逐像素对比验证 BSP 排序的正确性。
- **多边形分割**：使用 Sutherland-Hodgman 风格的分割将跨平面多边形裁剪为 front/back 两侧片段。
