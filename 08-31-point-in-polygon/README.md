# Point-in-Polygon Test (Ray Casting + Winding Number)

日期：2026-08-31
方向：计算几何

## 技术点
1. **射线投射法（Ray Casting / Even-Odd Rule）** —— 从查询点向 +x 方向发出一条射线，统计与多边形各边的交点数；奇数在内部、偶数在外部。适合简单应用，O(n) 每条边。
2. **环绕数法（Winding Number）** —— 统计多边形绕查询点的带符号圈数，`wn != 0` 即为内部。对自交多边形有更健壮的语义。
3. **鞋带公式（Shoelace Formula）** —— 计算多边形精确（带符号）面积，作为蒙特卡洛面积估算的 ground truth。
4. **蒙特卡洛面积验证** —— 在包围盒内撒 400,000 个随机点，用"内部点比例 × 包围盒面积"估算面积，与鞋带公式精确面积对比，误差应 < 5%。
5. **交叉验证** —— 对每个随机点，射线法与环绕数法结果必须 100% 一致（convex / triangle / concave / star 四种多边形）。
6. **PPM 可视化** —— 将四个多边形按分类着色填充内部并描白边，输出 800×600 图像。

## 算法原理

**射线投射法**（偶奇规则）：
对每条边判断射线是否穿越。仅当边的一个端点在射线下方、另一个在上方时，计算射线与该边的交点 x 坐标；若交点在查询点右侧（`q.x < xint`），则翻转 inside 标志。

**环绕数法**：
对每条有向边，根据端点跨越情况累加带符号交叉次数。`wn=+1`（逆时针绕一圈）在内部，`wn=0` 在外部。对自交多边形，环绕数能正确区分"被包围程度"。

**鞋带公式**（面积 ×2）：
```
2·Area = | Σᵢ (xᵢ · yᵢ₊₁ − xᵢ₊₁ · yᵢ) |
```

- ✅ 射线法与环绕数法在 1,600,000 个随机点上 100% 一致（0 不一致）
