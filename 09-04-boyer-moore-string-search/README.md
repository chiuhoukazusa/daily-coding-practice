# Boyer-Moore String Search

字符串算法：Boyer-Moore 精确字符串匹配（坏字符规则 + 好后缀规则），带朴素搜索基准对比 + 正确性/加速比量化验证。

## 编译运行

```bash
g++ main.cpp -o output -std=c++17 -O2 -Wall -Wextra
./output
```

## 输出结果

文本输出 `bm_output.txt`，包含 50000 个随机用例正确性验证 + 性能基准（比较次数/时间双维度加速比）+ 10 个边界用例断言式验证。

## 技术要点

- **坏字符规则（Bad Character）**：`bad_char[c]` = 模式中字符 `c` 最靠右位置到末尾的距离，失配时按该字符在模式中的最右出现位置位移
- **好后缀规则（Good Suffix）**：`suffix[i]` 表记录以 `i` 结尾的模式前缀与模式后缀的最长匹配，失配时尝试将已匹配的后缀对齐到模式中的相同子串
- **双规则取最大位移**：`i += max(bc_shift, gs_shift)`，保证正确性的同时最大化每次跳跃
- **正确性验证**：50000 个随机用例与朴素搜索结果完全一致
- **量化加速比**：比较次数加速比 8.73x（BM 显著减少字符比较，O(n/m) 最优情况下远低于朴素 O(n·m)）
