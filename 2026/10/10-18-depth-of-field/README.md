# Depth of Field Renderer (景深渲染器)

**日期**: 2026-10-18
**技术标签**: 景深, 弥散圆 (Circle of Confusion), 薄透镜模型 (Thin-Lens Model), 蒙特卡洛采样

## 核心思路

本渲染器采用**薄透镜模型 (Thin-Lens Model)** 模拟真实相机的景深效果：

1. 光线不再从单一针孔发出，而是从**孔径 (aperture) 半径为 A 的透镜盘**上的随机点发出（蒙特卡洛采样）。
2. 每条光线穿过**焦平面 (focal plane)** 上的传感器像素点，方向由 `透镜点 → 传感器点` 决定。
3. 位于焦平面距离 `z = focalDist` 的物体会聚到传感器上的同一点，因此**始终清晰**。
4. 位于焦平面前后（`z ≠ focalDist`）的物体，其光线在传感器上发散为**弥散圆 (Circle of Confusion)**，模糊程度随 `|z - focalDist|` 和孔径 A 增大而增大。

## 场景与验证

场景放置三颗高频棋盘格纹理的球体，分别位于：
- **近处** `z = 2.5`（焦平面前）
- **焦点处** `z = 5.0`（焦平面上）
- **远处** `z = 8.0`（焦平面后）

渲染同一场景在 **7 种孔径**（0.00 ~ 0.14）下的图像，并用**局部梯度能量 (local gradient energy)** 作为锐度量化指标，对三颗球的区域分别测量。

四项自动断言 **全部通过 (PASS)**：

1. ✅ 焦平面在所有孔径下保持清晰（所有孔径焦点锐度 ≥ 60% 针孔值）
2. ✅ 近处平面锐度随孔径增大单调递减

4. ✅ 最大孔径下，非焦平面的模糊比例 > 焦平面（弥散圆理论验证）

### 关键物理量

在最大孔径 (0.14) 下，各平面相对针孔图像的清晰度保留率：
- 焦点平面：保留 **77.5%** 锐度
- 近处平面：保留 75.4% 锐度
- 远处平面：保留 **41.3%** 锐度（离焦平面最远，模糊最严重，符合弥散圆理论）
