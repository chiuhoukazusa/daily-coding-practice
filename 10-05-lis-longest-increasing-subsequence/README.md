# Longest Increasing Subsequence (LIS) — 最长上升子序列

## 技术标签
算法 / 动态规划 DP / 最长上升子序列 LIS / Patience 贪心 / 二分 lower_bound

## 问题与原理

最长上升子序列（Longest Increasing Subsequence, LIS）问题：给定一个长度为 n 的序列
`a[0..n-1]`，求其中最长的**严格递增**子序列的长度（子序列不要求连续，只要求保持原顺序）。

本项目实现并对照验证了三种算法：

### 1. O(n²) DP（经典动态规划）
设 `dp[i]` 为「以 a[i] 结尾的最长上升子序列长度」，转移方程：

```
dp[i] = 1 + max{ dp[j] : j < i 且 a[j] < a[i] }
```

答案为 `max(dp[i])`。每个 i 需要扫描前面所有 j，故 O(n²)。

### 2. O(n log n) Patience 贪心（仅算长度）
维护一个数组 `tails[k]` = 「长度为 k+1 的递增子序列的最小可能结尾元素」。
对每个元素 x，用 `lower_bound` 找到第一个 `tails[pos] >= x` 的位置：

- 若 pos 在末尾 → 追加 x（子序列变长）
- 否则 → `tails[pos] = x`（让该长度的结尾更小，利于后续扩展）

`tails` 始终有序，每次二分 O(log n)，故总 O(n log n)。这就是著名的「耐心排序（Patience
Sorting）」思想。

### 3. O(n log n) Patience + parent 指针重建真实子序列
在 Patience 基础上额外记录 `parent[i]`（a[i] 作为子序列第 pos 位时，前驱元素下标），
最终从最长子序列的结尾回溯得到一条真实、严格递增、长度正确的 LIS。

## 四项量化验证

1. **穷举验证**：2000 条长度 ≤15 的序列，用 O(2^n) 暴力枚举逐条比对三种实现的 LIS 长度，0 不匹配。
2. **随机一致性**：10000 条长度 ≤200 的随机序列，三种实现长度一致；且重建出的子序列
   严格递增、长度等于 LIS 长度（0 非法重建）。
3. **边界用例**：严格递增 / 严格递减 / 全等 / 空序列 / 单元素 / 混合乱序，逐一验证，
   特别是「严格递增」语义下全等序列 LIS=1（而非 5）。
4. **性能**：n=100000 时 O(n log n) Patience 约比 O(n²) DP 快 3345 倍，验证渐进复杂度。

## 技术要点

- Patience 贪心的不变量：`tails` 始终单调不减，长度即 LIS 长度
- `lower_bound` 处理「严格递增」（相等元素不构成上升）
- parent 指针 + 回溯从「最长长度」重建一条真实 LIS（复杂度不退化）
- 暴力穷举作为「可证正确」的 ground truth，保证三种实现都不可能是「碰巧都错」
