## 技术要点

- 将每个立方体单元沿主对角线 `0→7` 剖分为 **6 个四面体**，共享面对角线方向一致，保证输出的等值面网格**闭合且无歧义**（Marching Cubes 的 256 种拓扑歧义问题不复存在）。
- 每个四面体只有 3 种拓扑（`cnt=0/3/4` 个交点），交点数为 3 时生成 1 个三角形，为 4 时按凸四边形切成 2 个三角形。
- 交点位置用线性插值 `t = (0 - v[a]) / (v[b] - v[a])` 在四面体棱边上求取。
- 用标量场梯度统一三角形法线朝向（指向外侧），保证流形网格朝向一致。
- **量化验证**：以解析球面面积 `4πR²` 与球体体积 `4/3πR³` 为基准，验证面积相对误差与体积相对误差均 < 5%，并检查无退化三角形（最小面积 > 1e-12）。
