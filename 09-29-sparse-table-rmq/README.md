# Sparse Table RMQ (Range Minimum Query)

**日期**: 2026-09-29
**方向**: 数据结构 / 静态数组区间查询
**核心技术**: Sparse Table 稀疏表 / RMQ 区间最值查询 / O(1) 查询 / 预处理 O(n log n) / 朴素循环基准对比

## 概述

**Sparse Table（稀疏表）** 是解决**静态数组区间最值查询（Range Minimum/Maximum Query, RMQ）**
的经典数据结构。它通过 **O(n log n)** 的时间与空间进行预处理，之后每次区间查询仅需 **O(1)** 时间。

核心思想是**倍增预处理**：定义 `st[k][i]` 表示「从下标 `i` 开始、长度为 `2^k` 的区间内的最小值」。
对于任意查询区间 `[l, r]`，令 `k = floor(log2(r - l + 1))`，则用两个**可能重叠**的长度 `2^k` 区间
`[l, l + 2^k - 1]` 与 `[r - 2^k + 1, r]` 覆盖整个查询区间：

```
RMQ(l, r) = min( st[k][l], st[k][r - 2^k + 1] )    其中 k = log2[r-l+1]
```

由于 `2^k + 2^k >= (r - l + 1)`（两个区间并集必然覆盖整个查询段），且取 `min` 是**幂等运算**
（重叠部分取两次最小值不影响结果），因此这一方法严格正确。

## 实现要点

- **预处理 `build`**：`st[0][i] = a[i]` 作为最底层（长度 `2^0 = 1`）；逐层递推
  `st[k][i] = min(st[k-1][i], st[k-1][i + 2^(k-1)])`，即把长度 `2^k` 拆成两个长度 `2^(k-1)` 的前后段。
- **log2 预计算**：用 `log2_[i] = log2_[i/2] + 1` 递推，O(n) 建出整型下取整的 log2 表，查询时 O(1) 取用。
- **查询 `query(l, r)`**：取 `len = r - l + 1`，`k = log2_[len]`，返回 `min(st[k][l], st[k][r - 2^k + 1])`。

**适合场景**：静态（不可修改）数组上的频繁 RMQ 查询。因为不支持高效的单点更新
（更新需要重建整个表），数组一旦确定就保持不变时，Sparse Table 是 O(1) 查询的最优选择之一。
