# Ant Colony Optimization for TSP

算法/图算法：蚁群优化求解旅行商问题（TSP），带贪心基线 + 2-opt 局部精化 + 小规模暴力搜索交叉验证。

## 编译运行

```bash
g++ main.cpp -o output -std=c++17 -O2 -Wall -Wextra
./output
```

## 输出结果

文本输出 `aco_tsp_output.txt`，包含 n=60 实例的完整断言式量化验证 + n=8 小实例暴力搜索交叉验证。

## 技术要点

- **蚁群优化 ACO**：经典 Ant System，信息素矩阵 + 轮盘赌概率路径构建
- **信息素蒸发/更新**：ρ 蒸发系数 + 每只蚂蚁按 `1/L` 沉积（对称 TSP）
- **贪心最近邻初始化**：用 NN 巡回路长度初始化信息素 `τ0 = n / C_nn`
- **2-opt 局部搜索**：边交换精化，保证巡回路长度单调不增
- **最优性验证**：n=8 小实例上 ACO 精确恢复暴力搜索最优解（≤0.1% 误差）
