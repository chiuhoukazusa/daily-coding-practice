# Median of Medians Linear Selection (BFPRT)

日期：2026-11-20
方向：算法 / 分治

## 技术点

- **Median of Medians (BFPRT)**：确定性线性时间第 k 小选择算法，分组取中位数递归构造好枢轴，最坏情况 `O(n)`，区别于 Quickselect 的 `O(n^2)` 最坏情况。
- **分组取中位数** (`median5`)：每组最多 5 个元素，插入排序取中位数。
- **Quickselect 基准对比**：随机枢轴的期望 `O(n)` 但最坏 `O(n^2)`，用于量化 BFPRT 在最坏/对抗输入下的优势。
- **插入排序小分组** (`insertionSort`)：`n ≤ 5` 时插入排序常数极小，作为分组内排序的底层原语。

## 核心思想

给定数组 `a` 与目标序号 `k`，BFPRT 将数组按 5 个一组划分，取每组中位数组成新数组，递归求其中位数的中位数作为枢轴 `p`，再按 `p` 三路划分：

- 枢轴至少保证了 $\lceil n/10 \rceil$ 的元素在两侧，从而每次至少缩减 30% 的规模，保证线性。

```
T(n) ≤ T(n/5) + T(7n/10) + O(n)  →  T(n) = O(n)
```

## 踩坑记录

1. **分组取中位数的边界处理**：最后一组不足 5 个时需特殊处理，组大小 `n ≤ 5` 直接插入排序返回中位数，避免下标越界。
2. **比较计数判定**：`cmpCount` 作为全局变量，在 `-O2` 下若未用 `volatile` 或输出 sink 可能被死代码消除，需确保结果写入输出文件。
3. **BFPRT vs Quickselect 性能辨析**：随机/均匀输入下 Quickselect 常数更小（枢轴质量足够），BFPRT 的比较次数常数因子略高，但其**最坏情况 `O(n)` 的确定性保证**才是价值所在——对抗输入下不会退化为 `O(n^2)`。
